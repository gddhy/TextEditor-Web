## 修复 PWA WCO 下 appbar 操作按钮与标题显示问题
- 根因 1：`@media (max-width: 720px)` 中 `.brand-name { display: none; }` 把 PWA/小窗口下的标题文字直接隐藏，导致左侧只剩图标。
- 根因 2：`.appbar-brand` 与 `.brand-name` 在 flex 收缩时没有正最小宽度保护，标题文字/品牌区会被压到 0。
- 修改 `css/app.css`：
  - `.appbar-brand` 加 `min-width: 120px;`，保证品牌区至少能显示图标+几个汉字。
  - `.brand-name` 改 `min-width: 4em;`，防止在 flex 容器里被压到 0，同时保留截断能力。
  - `@media (max-width: 720px)`：不再 `display:none` 标题，改为 `max-width: 120px;` 截断；并仅在 `:root.wco` 下隐藏 `#btnNew`/`#btnDownload`，缓解 PWA 小窗口右侧系统占位导致操作栏拥挤。
- `sw.js`：VERSION v27 → v28（改 CSS 必 bump）。
- 校验：`node --check` app.js/files.js/sw.js 通过；agent-browser 本地测试页验证 500px/600px/700px/900px WCO 与普通浏览器 600px，左侧菜单+图标+标题均可见，右侧按钮不再被挤出或挤在一起。

## 修复 PWA WCO 下 appbar 按钮完全消失
- 根因：WCO 的 `env(titlebar-area-width)` 是标题栏**可用区域**宽度（左侧可绘制内容宽度），不是右侧系统控件宽度。之前 CSS 和 JS 都把它当作系统控件宽度来用，导致 PWA 下 `padding-right` 几乎等于整个窗口宽度，把 `.appbar-actions` 全部挤出可视区。
- 正确公式：系统控件宽度 = `100vw - env(titlebar-area-x, 0px) - env(titlebar-area-width, 100vw)`；JS 中对应 `window.innerWidth - getTitlebarAreaRect().right`。
- 修改：
  - `css/app.css`：`.appbar` 的 `padding-right` 改为 `calc(100vw - env(titlebar-area-x, 0px) - env(titlebar-area-width, 100vw) + env(safe-area-inset-right, 0px))`。
  - `js/app.js`：`setupWindowControlsOverlay` 中 `--wco-right` 改为 `Math.max(0, Math.ceil(window.innerWidth - r.right))`。
  - `css/diff.css`：`.diff-bar::after` 的 env 回退也改为同样的正确公式。
- `sw.js`：VERSION v28 → v29。
- 校验：`node --check` app.js/files.js/sw.js 通过；本地测试页复现 bug（padding-right = 可用宽度 → actionsW=0）并验证修复后（padding-right = 系统控件宽度 → actionsW=580/按钮 40px 正常显示）。
